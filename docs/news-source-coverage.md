# ニュース取得元の調査・カバレッジ台帳

最終確認日: 2026-10-01

## 現在の実装対象

| 取得元 | 経路 | 地域カバレッジ | 状態・注意 |
|---|---|---|---|
| Google News | 既存の検索RSS | 検索に掲載された範囲 | 補助経路。これだけでは不十分 |
| Yahoo!ニュース 国内・地域 | `topics/domestic.xml`, `topics/local.xml` | 全国・地域トピックス | Yahoo!公式ヘルプがトピックスRSSを案内。編集されたトピックスであり、全配信記事を網羅するフィードではない |
| Yahoo!ニュース 提供元別RSS | 公式RSS一覧 `/rss/` から配信元RSSを抽出 | 地方紙・地方局を含む配信パートナー | 実測で661配信元のうち、地方紙・放送局等の名称ルールに合う197フィードを選択。2時間で一巡するよう交互に取得。掲載パートナー全体ではない |
| NHK 社会・主要 | `cat1.xml`, `cat0.xml` | 全国ニュース、一部の地方発記事 | 社会カテゴリを追加。地方局の全記事を網羅するものではない |
| 日テレNEWS NNN | `rss/index.rdf` | NNN加盟局の記事 | NNN公式のRSS案内を利用。記事一覧ページの自動クロールは利用条件で禁止されているため行わない |
| FNNプライムオンライン | `list/feed/rss` | FNN加盟局の記事 | RSSエンドポイントを利用。取得成否を監視 |
| TBS NEWS DIG | 国内一覧ページ | JNN地域局の記事 | 一覧ページを補助取得。リンク先本文は既存の本文抽出・事実ゲートを通す |
| テレ朝NEWS | 社会ニュース一覧 | ANN報道の一部 | 一覧ページを補助取得。取得成否を監視 |
| 千葉県警 | 最新事件・事故ファイル | 千葉県 | 公式発表を直接確認する初期アダプター。警察庁の一覧が示す47都道府県警のうち1都道府県のみ実装済み |

## 調査で確認した一次資料

- Yahoo!ニュースは、記事見出し等のRSS配信、国内・地域等のカテゴリ別トピックスRSS、および情報提供元別のRSS（各提供元の最新記事最大50件）を案内している。トピックスRSSはカテゴリごとに最新8件と説明されている。配信元別RSS一覧は実際に取得して661件を確認し、配信元名で地方紙・地方局等を選んだ197フィードを登録対象にした。
- 日テレNEWS NNNは公式に `https://news.ntv.co.jp/rss/index.rdf` を案内する一方、利用条件で自動スクレイピングを禁止している。公式RSSだけを使う。
- 警察庁は都道府県警察本部リンクを公開している。各県警の発表ページ構造は個別確認が必要で、千葉県警アダプターを全国対応と誤認しない。
- 国立国会図書館の新聞社サイト集には、全国紙・地域別の地方紙・通信社が掲載される。サイト一覧への掲載だけでは、RSSの存在や自動取得・見出し再利用の許諾を意味しない。

## 全国網羅に向けて残る作業

1. 警察庁の47本部一覧を起点に、各警察の「事件・事故」「逮捕・検挙」公式更新ページ、RSS/APIの有無、利用条件、更新頻度を個別に記録する。
2. Yahoo!提供元RSSにまだ含まれない地方紙・地域局を、国立国会図書館の地方紙一覧とJNN/FNN/ANN/NNNなどのネットワーク一覧と照合して登録する。
3. 公式RSSのないサイトは、利用条件とrobots.txtを確認し、許諾を確認できない自動巡回は有効化しない。
4. 取得元ごとに最終成功時刻、HTTP状態、候補数、記事公開日時の遅延を記録し、障害とカバレッジ低下を検知する。
5. 媒体の異なる同一事件は既存の事件フィンガープリントで1件にまとめ、追加出典を保持する設計へ進める。

この台帳は「日本の報道を完全網羅した」と示すものではない。確認済みの登録先・未登録領域・利用上の制約を明示し、拡張状況を追跡するためのもの。
